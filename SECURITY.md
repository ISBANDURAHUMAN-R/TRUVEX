## Reporting a Vulnerability

The TruVex AI team takes software security and user privacy seriously.

If you believe you have found a security vulnerability in TruVex AI:
1. **Do not open a public GitHub issue.**
2. Send an advisory or report directly to the repository maintainer:
   - Email: **riyasfamily7@gmail.com** (Maintainer: ISBANDU RAHUMAN R)
3. Please include:
   - A description of the issue and potential impact
   - Step-by-step instructions or proof-of-concept to reproduce
   - Suggested mitigations if known

We will acknowledge receipt within 48 hours and work diligently to release a patch promptly.
